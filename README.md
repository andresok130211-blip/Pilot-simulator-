# ✈ Pilot Sim — симулятор пилота авиалайнера

Вы пилот пассажирского самолёта: выбираете рейс между аэропортами, взлетаете, ведёте самолёт и аккуратно садитесь. Чем плавнее полёт и мягче посадка, тем больше зарабатываете. На деньги покупаете самолёты побольше.

## Как получить APK (всё делается с телефона через github.com)

Нужны всего два файла: `www/index.html` (вся игра в одном файле) и `.github/workflows/build-apk.yml`.

1. github.com → **New repository** → имя `pilot-sim` → **Public** → Create.
2. **Add file → Upload files** → выберите `index.html`. Но он должен лежать в папке `www`, поэтому надёжнее: **Add file → Create new file**, в имени введите `www/index.html`, вставьте содержимое файла → **Commit changes**.
3. Так же создайте файл `.github/workflows/build-apk.yml` и вставьте содержимое `build-apk.yml`.
4. Вкладка **Actions** → «Build APK» стартует сама (или **Run workflow**). 5–10 минут.
5. Готовый APK: **Releases** → `Pilot Sim (последний APK)` → `pilot-sim.apk`.
6. Откройте APK на телефоне и разрешите установку из неизвестных источников.

Исходники лежат в `src/`; `node tools/build.mjs` собирает их в `www/index.html`.

## Управление

- **Слева — газ** (ползунок вверх — больше тяги).
- **Справа — ручка**: вверх — нос вверх, вниз — нос вниз, отпустили — самолёт выравнивается.
- Кнопки внизу: ШАССИ, ЗАКР −/+, ТОРМОЗ, ×N (ускорение времени), А/П, А/Т (автомат тяги), ВЫС −/+, ПОСАДКА (заход по глиссаде).
- На компьютере: W/S или стрелки — ручка, Shift/Ctrl — газ, G шасси, F закрылки, B тормоз, A автопилот.

## Как лететь

1. **Взлёт:** закрылки 1+, газ на максимум, на скорости отрыва потяните ручку вверх.
2. **Полёт:** включите АП, высоту задайте ВЫС −/+.
3. **Посадка:** следуйте за зелёной пунктирной глиссадой, шасси и закрылки выпущены, касание мягкое (до −3 м/с), затем ТОРМОЗ.

В меню есть галочка **Помощник**: с ней автопилот сам ведёт по глиссаде, держит скорость, выпускает шасси и закрылки и тормозит после посадки. Без неё всё вручную.

## Играть в браузере

Откройте `www/index.html` в любом браузере (после `node tools/build.mjs`).
