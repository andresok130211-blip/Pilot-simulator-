# ✈ Pilot Sim — симулятор пилота авиалайнера

Вы пилот пассажирского самолёта: выбираете рейс между аэропортами, взлетаете, ведёте самолёт и аккуратно садитесь. Чем плавнее полёт и мягче посадка, тем больше зарабатываете. На деньги покупаете самолёты побольше.

## Как получить APK (всё делается с телефона через github.com)

Нужны всего два файла: `www/index.html` (вся игра в одном файле) и `.github/workflows/build-apk.yml`.

1. github.com → **New repository** → имя `pilot-sim` → **Public** → Create.
2. **Add file → Upload files** → выберите `index.html`. Но он должен лежать в папке `www`, поэтому надёжнее: **Add file → Create new file**, в имени введите `www/index.html`, вставьте содержимое файла → **Commit changes**.
3. Так же создайте файл `.github/workflows/build-apk.yml` и вставьте содержимое `build-apk.yml`.
4. Вкладка **Actions** → «Build APK» стартует сама (или **Run workflow**). 5–10 минут.
5. Готовый APK: **Releases** → `Pilot Sim (последний APK)` → `pilot-sim.apk`.
6. Откройте APK на телефоне и разрешите установку из неизвестных источников.

Исходники лежат в `src/`; `node tools/build.mjs` собирает их в `www/index.html`.

## Управление

- **Слева — газ** (ползунок вверх — больше тяги).
- **Справа — штурвал**: вправо/влево — крен и поворот, вверх/вниз — нос вверх/вниз. Отпустили — штурвал возвращается в центр.
- Кнопки внизу: ШАССИ, ЗАКР −/+, ТОРМОЗ, ×N (ускорение времени), А/П, А/Т (автомат тяги), ВЫС −/+, НАВ (автопилот возвращает на курс), ПОСАДКА (заход по глиссаде).
- На компьютере: стрелки (или W/S/D) — штурвал, Shift/Ctrl — газ, G шасси, F закрылки, B тормоз, A автопилот.

## Полный цикл рейса

Гейт → рулёжная дорожка (жёлтая линия) → полоса → взлёт → полёт → посадка → съезд с полосы → рулёжка → гейт. Помощник может сам рулить по жёлтой линии (кнопка АВТО РУЛ), вам остаётся тормоз; ползунок газа в нижней трети — скорость руления. Кнопка ВИД переключает вид снаружи (с 3-го лица) и из кабины.

## Как лететь

1. **Взлёт:** закрылки 1+, газ на максимум, на скорости отрыва потяните ручку вверх.
2. **Полёт:** включите АП, высоту задайте ВЫС −/+.
3. **Посадка:** следуйте за зелёной пунктирной глиссадой, шасси и закрылки выпущены, касание мягкое (до −3 м/с), затем ТОРМОЗ.

В меню есть галочка **Помощник**: с ней автопилот сам ведёт по глиссаде, держит скорость, выпускает шасси и закрылки и тормозит после посадки. Без неё всё вручную.

## Аварийные ситуации (ЧП) и ранги

В полёте случаются отказы (частота настраивается перед рейсом: выкл / редко / иногда / часто):

- отказ двигателя на разбеге (до V1 — прервать взлёт, после — взлетать), отказ двигателя в полёте;
- пожар двигателя — быстро нажмите ТУШЕНИЕ, иначе огонь перекинется на крыло;
- птицы в двигатель (иногда с полным отказом);
- отказ гидравлики — заклинило закрылки, шасси выпускается кнопкой ЗАПАС. ШАССИ, посадка на повышенной скорости;
- разгерметизация — АВАР. СНИЖ. до 3000 м;
- отказ автопилота и автомата тяги — пилотируйте вручную;
- техника на полосе — кнопка УХОД, самолёт сам зайдёт на второй круг.

Справа вверху показывается чек-лист действий. За верные решения платят премию и дают опыт (XP) — растёт ранг от «Курсанта» до «Легенды авиации». Потренироваться можно в «Тренажёре ЧП» из главного меню.

Проверка сценариев ботом: `node tools/emerg-test.mjs` (по одному) и `node tools/emerg-rand.mjs` (случайные рейсы).

## Ландшафт и запасные аэродромы

Под самолётом — процедурный ландшафт: поля, леса, озёра и реки, города (ночью — огни), холмы и горы вдали, дымка по расстоянию. Холмы настоящие: «ЗЕМЛЯ ВПЕРЕДИ!» предупреждает о рельефе, столкновение с землёй — катастрофа. Рядом с аэродромами земля плоская.

Вдоль трассы расположены запасные аэродромы (настоящие аэропорты рядом с маршрутом и аэродромы «Запасной N»). Кнопка **ЗАПАСНЫЕ АЭРОДРОМЫ** (при ЧП подсвечена красным) показывает список со стрелкой направления и расстоянием; нажмите на аэродром — автопилот ведёт к нему, садитесь как обычно. Рейс при посадке на запасном оплачивается частично (×0.4), самолёт остаётся в городе назначения.

## Текстуры

Земля: борозды на полях, дороги, подлесок, блики на воде. Аэродром: покос газона, швы и заплатки асфальта, следы резины в зоне приземления, плиты перрона, окна и цоколь зданий, самолёты на стоянке. Самолёт: 12-гранный фюзеляж с обтекателем и лобовыми стёклами, иллюминаторы, ливрея в цвет хвоста, двери, крыло с предкрылками и опускающимися закрылками, элероны, законцовки, двигатели с пилонами и соплами, объёмный киль с логотипом, двойные колёса шасси, блики металла. Облака объёмные, с мягкими краями.

## Играть в браузере

Откройте `www/index.html` в любом браузере (после `node tools/build.mjs`).
